# ObraCusto

Custeio de obras para uso interno: escolhe os produtos e as quantidades, e o app soma as matérias-primas de cada um para chegar no custo.

**Abrir o app:** https://victorreis18.github.io/obracusto/

Para ter o ícone na área de trabalho, instale o site como app:
- **Chrome:** menu ⋮ → Transmitir, salvar e compartilhar → Instalar página como app
- **Edge:** menu … → Aplicativos → Instalar este site como um aplicativo

Os dados de custo não ficam neste repositório. O app busca os preços direto da planilha da empresa no Google, com o login de cada pessoa (só leitura).

Como usar, atualizar preços e publicar mudanças: [LEIA-ME.md](LEIA-ME.md).
